## 三、简短结论

1. **工具页方向**：5 个工具页都面向高搜索量的 Transactional 关键词，但 SERP 几乎被 iLovePDF、Smallpdf、Adobe 三巨头垄断。removepdfpages.net 作为新站，直接硬拼主词难度大，建议先用 **“无登录、更轻量、单一功能做到极致”** 的差异化定位切长尾。
2. **机会排序**：`Merge PDF`（165K）> `Compress PDF`（135K）> `Convert PDF to Word`（90.5K）> `Remove PDF Pages`（27.1K）> `Sign PDF`（14.8K）。前三个搜索量最大，但竞争也最激烈；`Sign PDF` 虽然量小，CPC 高达 $3.36–$5.20，商业意图强。
3. **Blog 机会**：你提供的“替代型”关键词（Foxit alternative、one-time payment / no subscription PDF editor）商业意图明确，适合用来吸引高转化流量；`replace image in PDF` 和 `how to reduce pdf file size without losing quality` 则是偏教程的搜索，可用于获取外链和信任。
4. **数据限制**：Google/Bing 反爬阻挡，SERP 数据来自 Yahoo 代理；工具页搜索量/CPC 以 DataForSEO 为准，Blog 主题词优先采用 SEMRUSH（你自查）数据。DataForSEO 对部分词存在明显低估，已按 SEMRUSH 修正。
